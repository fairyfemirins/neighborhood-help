# White Paper: Neighborhood Help App

## Problem Statement
People struggle to find **reliable, local help** for small tasks (e.g., plumbing, gardening, babysitting). Commercial platforms (e.g., TaskRabbit, Thumbtack) are expensive and lack community trust.

## Solution
A **mobile-friendly web app** that:
- Connects users with **trusted neighbors and local handymen**. 
- Supports **user profiles, job posting, matching, and reviews**.
- Focuses on **local, community-driven** solutions.

## Design Decisions
1. **Flask + SQLite:** Lightweight, easy to deploy, and scalable for small communities.
2. **Mobile-Friendly Frontend:** Bootstrap for responsive design.
3. **User Roles:** Separate dashboards for users and helpers.
4. **Reviews:** Crowdsourced ratings for trust and safety.

## Future Work
- **Real-Time Chat:** Enable communication between users and helpers.
- **Payment Integration:** Secure payments via Stripe or PayPal.
- **Background Checks:** Verify identities for safety.

## Conclusion
This app fills a gap for **local, trustworthy help** by connecting neighbors and handymen in a **community-driven** platform.
